# WallCraft 🎨

**The Automated, Production-Ready Wallpaper Engine for Developers.**

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-production--ready-success)
![Theme](https://img.shields.io/badge/themes-Nord%20%7C%20Dracula%20%7C%20Gruvbox-purple)

WallCraft is a robust, open-source platform that automatically fetches high-quality photography from Unsplash, applies developer-favorite themes (like Nord, Dracula, and Gruvbox), and hosts them in a beautiful Next.js gallery.

**[View Live Demo](https://dev-AshishRanjan.github.io/wallcraft/)**

---

## ✨ Features

- **🤖 Automated Pipeline:** A GitHub Action runs hourly to fetch, process, and release new wallpapers.
- **🎨 Multi-Theme Support:** Converts images pixel-by-pixel to Nord, Dracula, Gruvbox, Catppuccin, and more.
- **⚡ Zero-API Architecture:** The frontend runs without a backend database. It reads directly from a JSON index generated by the build pipeline.
- **🖌️ WallCraft Studio:** A client-side tool to drag & drop your _own_ images and theme them instantly in the browser.
- **🔒 Private & Secure:** Studio processing happens 100% on your device via HTML5 Canvas.
- **📦 4K Ready:** All wallpapers are processed at 3840px width.

---

## 🏗️ Architecture

WallCraft uses a unique **"Decoupled Data"** architecture to remain free, scalable, and robust.

1.  **The Brain (Node.js Script):** \* Fetches 4K images from Unsplash.
    - Uses `sharp` and Euclidean distance algorithms to map pixels to theme palettes.
    - Updates `public/database.json` and commits changes to the repo.
2.  **The Storage (GitHub Releases):**
    - Processed images are uploaded as binary assets to GitHub Releases (Unlimited bandwidth/storage).
3.  **The Frontend (Next.js + Shadcn):**
    - A static site hosted on GitHub Pages.
    - Fetches the `database.json` via CDN (jsDelivr) for instant load times.
    - Includes a client-side image processor for the Studio.

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- An Unsplash API Key (Free Demo tier is sufficient).

### 1. Installation

```bash
git clone [https://github.com/dev-AshishRanjan/wallcraft.git](https://github.com/dev-AshishRanjan/wallcraft.git)
cd wallcraft
npm install
```
